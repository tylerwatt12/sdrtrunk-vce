How to review: choose one area and read the rows as product choices, not programming tasks. Use My review on each row to approve it, record a different decision, or leave a question. Move to web keeps the feature in a new location. Redesign keeps the purpose but changes how it works. Remove intentionally retires it. Suggested means it was found in the old interface but has not been approved. Your decision needed marks a choice that has no safe default.
