What’s New in Alpha 5

Alpha 5 makes updates easier to understand, improves help when something goes wrong, and makes P25 and web-call information clearer.

This is still alpha software. Stop sdrtrunk-vce and back up its portable data folder before replacing an earlier build.

Added

  • A one-time What’s New window. Starting with this release, a plain-language summary opens automatically the first time you run each new public version. It does not interrupt later launches. You can open it again from the Help menu.
  • Bug reports from inside the application. Help > Submit Bug Report lets you describe a problem, attach extra screenshots, and either send the report or save a ZIP for manual upload. Before anything is collected, the window explains exactly what is included and requires your consent.
  • More useful browser playback details. The web player now keeps aliases together with their talkgroup or radio number and shows the system, channel, frequency, slot, decoder, protected-call status, and call length when available.

Changed

  • P25 conventional imports are classified more accurately. A conventional P25 frequency imported from RadioReference now becomes a P25 Conventional channel instead of a trunked P25 control channel.
  • Older XML playlists are handled more carefully. Single-frequency P25 entries that look conventional are converted to P25 Conventional during a first-time import, while entries with strong signs of a trunked system are kept as trunked channels. Existing channels in an already-created portable database are not changed automatically.
  • Radio-system numbers are easier to read. Compact web tables use the familiar hexadecimal form, while detail pages show labeled hexadecimal and decimal values together where both are useful.
  • Documentation has current screen images and clearer feature descriptions. Obsolete screenshots were replaced with views of the current desktop and web interfaces, and a new signal-path and delay explanation helps identify where listening latency comes from.

Fixed

  • The browser player now correctly identifies whether a number is a talkgroup, radio, patch, or phone number and keeps the source-to-target relationship visible for playing and queued calls.
  • Packaged builds now retain the exact application version and build details used by diagnostics, making submitted reports easier to match to the correct release.

Removed

No user feature, setting, channel, alias, recording, or stored statistic is removed by this release. Only outdated documentation images were replaced.

Before You Upgrade

  • No database migration is needed from Alpha 4. Alpha 5 continues to use P25 history schema version 19.
  • Replace the application files instead of merging two releases together, and keep your portable data folder.
  • The new bug-report tool includes the current application screenshot, application log, sanitized configuration, exact tuner identifiers and serial numbers, hostname, and basic computer details. The report service records the public address used for the upload and normally retains a report for 30 days. Recordings, the key vault, passwords, API credentials, and security-key material are excluded. Screenshots are not automatically redacted, so review the on-screen disclosure before consenting.
  • The P25 import improvements affect new RadioReference or legacy-XML imports. Review newly imported channels as usual; existing portable-database channels are left alone.

Downloads: Use the package that matches your operating system and processor. Java is included. JMBE remains a separate setup under Preferences > Decoder > JMBE Audio Library. Verify the downloaded ZIP with SHA256SUMS.txt before installing.
