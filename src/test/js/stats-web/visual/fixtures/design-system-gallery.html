Composition guidance

Start with shared tokens and primitives, then choose the layout that best supports the workflow.

Consistent language, flexible pages

Keep controls, surfaces, type, and states consistent. A monitoring workspace, editor, and directory do not need the same layout.

Put tools where they act

Place compact table controls in the owning section header and let populated tables meet panel edges.

Design the narrow view intentionally

Turn dense rows into semantic cards or focused selectors; do not make phone users pan across desktop tables.

Keep related work in context

Open a focused child dialog to create a related item without losing the parent form or its selection.

Actions

Prefer compact icon-only actions when the symbol is familiar and space matters; always provide an accessible name and shared hover/focus hint. Keep visible text for ambiguous, primary, or high-consequence actions.

Use restrained semantic color plus text or icons; color is a landmark, never the only meaning.
